# path and pytest, which are needed to TRAIN and evaluate but never to SERVE.
# Render's free tier gives 512MB RAM, and shap + xgboost + matplotlib together
# push the image and the resident footprint uncomfortably close to that, so the
# deployment installs this narrower set instead.
#
# scikit-learn stays: joblib unpickles the model against it.
#
# xgboost-cpu instead of xgboost: the regular `xgboost` PyPI wheel
# unconditionally depends on nvidia-nccl-cu12 (~400MB) for multi-GPU training
# support this project never uses — CPU inference on an already-trained model
# never touches that code path. xgboost-cpu is the same library built without
# it: same import name (`import xgboost`), same API, loads this project's
# model.joblib without any changes. Verified: installed size drops from ~1.2GB
# to ~620MB, and predict_proba()/SHAP output are identical on the shipped
# artifact. Needs scikit-learn present (already required above).
